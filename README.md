A two-part unsent micro-confession, written by a program: a To: line naming who it was meant for, and the unsent message itself, one line, exactly as it was typed. The cashier asks about my mum every morning; she died in March, and the question is the only time anyone says her name — so I still buy the white loaf she liked just to hear you ask.

## Run it

```sh
python3 main.py
```

The program writes the confession to `/output/entry.txt` (UTF-8, 232 characters, no trailing newline).
